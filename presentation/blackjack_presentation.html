Every hand follows the same seven steps. The bet is validated and deducted. The shoe deals. The engine offers insurance and checks for naturals. The player acts. The dealer plays only if a hand is still live. Settlement pays each hand. The result is recorded for analytics.

Click any step to see the function that owns it. The UI never decides a rule. It asks the engine for the legal actions and then calls act.

def act(self, action: str) -> None:
    if self.state is not GameState.PLAYER:
        raise RuntimeError("The table is not accepting actions")
    available = self.available_actions()
    if action not in available:
        raise ValueError(f"Illegal action {action!r}")

    hand = self.player_hand

    if action == "hit":
        hand.add(self._draw())
        if hand.is_bust or hand.total == 21:
            hand.stood = True
        self._advance()
    elif action == "stand":
        hand.stood = True
        self._advance()

The engine is a small state machine. IDLE, INSURANCE, PLAYER, SETTLED. A hand can only start from IDLE or SETTLED. Player actions are only accepted in PLAYER.

The code first checks the legal action list, then mutates only the current hand, then advances to the next unfinished hand. That guard is why the CLI cannot ask for an illegal move. Click Next line to walk through it.

def _dealer_play(self) -> None:
    while True:
        total = self.dealer.total
        if total < 17:
            self.dealer.add(self._draw())
        elif total == 17 and self.dealer.is_soft and self.rules.dealer_hits_soft_17:
            self.dealer.add(self._draw())
        else:
            return

The dealer is a policy, not a personality. Draw below seventeen. Stand on soft seventeen. If the H17 rule is on, hit soft seventeen.

The demo starts with ace-six. In S17 the dealer stands. Toggle H17 and deal a card, and the dealer hits. This is deterministic, which is exactly what makes it testable. The tests stack the shoe with exact cards and check both rules.

Every payout is a formula. A win returns the stake plus the same amount. A blackjack returns the stake plus one and a half times the stake. A push returns the stake. A loss returns nothing. A surrender returns half. Insurance is a separate half-unit bet that pays two to one.

Move the slider and click an outcome. The key accounting rule is that total_wagered includes doubles, splits and insurance, so house edge is net divided by all money at risk.

09 · Advanced actions

A split is two hands with two wallets.

1 / 6 
def _split(self, hand: Hand) -> None:
    second = hand.cards.pop()
    new_hand = Hand(cards=[second], bet=hand.bet, is_split_hand=True)
    hand.is_split_hand = True

    self.bankroll -= hand.bet
    hand.add(self._draw())
    new_hand.add(self._draw())
    self.hands.insert(self.current + 1, new_hand)

    if hand.cards[0].is_ace and not self.rules.hit_split_aces:
        hand.stood = True
        new_hand.stood = True
    self._advance()

A split is two hands with two wallets. The second card becomes a new hand, and a second bet is posted. Each hand has its own cards, bet, doubled flag and result.

The demo walks through a split of eights. Hand one doubles to twenty-one, hand two stands on ten. The dealer busts. Both win, but the payouts are independent. There is a test that makes one hand win and the other lose, and checks the bankroll nets to zero.

def observe(self, card: Card) -> int:
    self.running_count += card.hi_lo_value
    self.cards_seen += 1
    return self.running_count

def true_count(self, decks_remaining: float) -> float:
    return self.running_count / max(0.5, decks_remaining)

Counting is arithmetic with a memory. Two through six are plus one. Seven through nine are zero. Ten through ace are minus one. The running count is the sum. The true count divides by the decks left.

Four betting systems. Flat always bets one unit. Martingale doubles after a loss and resets after a win. Hi-Lo spread sizes the bet from the true count. Half Kelly sizes from an estimated edge and variance.

The chart is one thousand rounds. The martingale can win a short session, which is exactly why short sessions are dangerous. Across 300,000-hand runs, the flat game paid the house about point three five percent; the Hi-Lo spread returned about point four eight percent to the player.
